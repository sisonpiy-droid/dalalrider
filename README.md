# DalalRider 🏍️📈🇮🇳

**Motocross meets Dalal Street.** An original open-source browser game by [**@sisonpiy-droid**](https://github.com/sisonpiy-droid) that turns live Indian stock market charts (**NSE & BSE**) into playable 2D physics motocross tracks.

Every bull rally is a launch ramp, every lower circuit is a cliff.

🔗 **Play Live:** [https://sisonpiy-droid.github.io/dalalrider/](https://sisonpiy-droid.github.io/dalalrider/)

---

## ✨ Features

- **Live NSE & BSE Market Data (in ₹ INR):**
  - **Trending Dalal Street Tracks:** `RELIANCE`, `ETERNAL` (Zomato), `TATAMOTORS`, `ADANIENT`, `HAL`, `TRENT` (Zudio), `INFY`, `HDFCBANK`, `NIFTY50`, plus 55+ preloaded NSE blue-chips & midcaps (`TCS`, `ICICIBANK`, `SBIN`, `BHARTIARTL`, `MARUTI`, `IRCTC`, `RVNL`, `MAZDOCK`, `BSE`, `CDSL`, etc.) with live quotes and 5-minute intraday candles.
  - **LIVE 1D Intraday Mode:** Ride today's 5-minute NSE candle action or switch to `1M`, `3M`, `6M`, `1Y`, and `ALL`.
  - **Indian Unicorns & New-Age Tech Mode:** Switch to the **UNICORNS** tab to ride India's top consumer-tech and fintech giants (`Eternal/Zomato`, `Swiggy`, `Paytm`, `Nykaa`, `Ola Electric`, `Policybazaar`, `Delhivery`, `Angel One`, `Jio Financial`, `IRCTC`, `CDSL`, `BSE`).
  - **Legendary Dalal Street Crashes 💀:** Survive historic Indian market wipeouts including `RCOM` (-99.8%), `JETAIRWAYS` (-95.0%), `UNITECH` (-99.9%), `HDIL` (-99.8%), `EDUCOMP` (-99.8%), `FRETAIL` (-99.2%), and `YESBANK` (-93.5%).
- **2D Motocross Physics Engine (`Matter.js`):**
  - Dual-wheel spring suspension, wheelies, stoppies, backflips, frontflips, supermans, no-handers, dead sailors, NITRO boost, moon launches, and ragdoll wipeouts.
  - Collect `₹` rupee coins along the price curve and build up to a `×5` streak multiplier.
- **Custom Share Cards:**
  - Export P&L cards, DalalRider NSE Terminal screenshots, Receipts, Holo Cards, Grand Prix Posters, or Crash Incident Reports.

## 🛠️ Tech Stack & Local Development

- **Engine:** TypeScript, HTML5 Canvas, Matter.js (2D rigid-body physics), WebAudio API procedural engine synthesizer
- **Bundler:** Vite

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
